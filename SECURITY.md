# Security Policy

## Supported Versions

Security support is provided for the latest `main` branch and the latest tagged release.

## Reporting a Vulnerability

Please report vulnerabilities privately and do not open a public issue with exploit details.

Preferred channel:
- Email: `security@elyx.finance`

Include:
- Affected contract/module
- Reproduction steps or proof of concept
- Impact assessment
- Suggested remediation (optional)

We aim to acknowledge reports within 72 hours.
