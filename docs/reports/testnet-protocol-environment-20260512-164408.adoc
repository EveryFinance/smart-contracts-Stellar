== Testing Instructions

Source deployment variables:

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260512-164408.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CARYJGQUCAWA5RRCPMKJ6WTIAHVX53FJL73TUTCY4TMZHWRQ2I6CWXH5" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CD5VOGLMNWV3JZIZI2YGNNJSXNLC7DIO7JQLJ6Z42OBAEOSPCIARIVI7" -- deposit --amount 1000000000 --from <G...USER> --asset "CARYJGQUCAWA5RRCPMKJ6WTIAHVX53FJL73TUTCY4TMZHWRQ2I6CWXH5" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CD5VOGLMNWV3JZIZI2YGNNJSXNLC7DIO7JQLJ6Z42OBAEOSPCIARIVI7" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CD5VOGLMNWV3JZIZI2YGNNJSXNLC7DIO7JQLJ6Z42OBAEOSPCIARIVI7" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CBMPOI5GWL2PHVW5FRGC2EDNNOGG4D7EZWQRKJX2XXHOR6NDVE66ZRYT" --fn-name supply --args '[{"i128":"300000000"}]'

Verify NAV and share price:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CD5VOGLMNWV3JZIZI2YGNNJSXNLC7DIO7JQLJ6Z42OBAEOSPCIARIVI7" -- get_nav
stellar contract invoke --network testnet --source-account "deployer" --id "CD5VOGLMNWV3JZIZI2YGNNJSXNLC7DIO7JQLJ6Z42OBAEOSPCIARIVI7" -- get_share_price
