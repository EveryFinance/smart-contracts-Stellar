== Testing Instructions

Source deployment variables:

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260513-022325.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CABDMREX2YDLYFA5AO3PMSNYHKJUWDRGUANN5IYASEXE5N25MZJ7QF67" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CA563NSJFCUS3S2MKHDXP42ZATEVW32LWNDG7FWYGTITFL46XRJGMFQG" -- deposit --amount 1000000000 --from <G...USER> --asset "CABDMREX2YDLYFA5AO3PMSNYHKJUWDRGUANN5IYASEXE5N25MZJ7QF67" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CA563NSJFCUS3S2MKHDXP42ZATEVW32LWNDG7FWYGTITFL46XRJGMFQG" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CA563NSJFCUS3S2MKHDXP42ZATEVW32LWNDG7FWYGTITFL46XRJGMFQG" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CCC52DELF7TLYHB7OBCSAAFZ54C2HBHBOZDPVURPHZRE23S6O5KEMW3O" --fn-name supply --args '[{"i128":"300000000"}]'

Verify NAV and share price:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CA563NSJFCUS3S2MKHDXP42ZATEVW32LWNDG7FWYGTITFL46XRJGMFQG" -- get_nav
