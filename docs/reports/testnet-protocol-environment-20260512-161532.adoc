== Testing Instructions

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260512-161532.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CAY6NM32TR3573JV6VFH6MC3P7JWWDZM7SDBQZAAK3DIY6F33MJSJ4CM" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CBLFJZNSQK5UKGAZQEA6VDLORNQKDGGRCOUTB4LGHBJ25RQZKXAM2DE2" -- deposit --amount 1000000000 --from <G...USER> --asset "CAY6NM32TR3573JV6VFH6MC3P7JWWDZM7SDBQZAAK3DIY6F33MJSJ4CM" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CBLFJZNSQK5UKGAZQEA6VDLORNQKDGGRCOUTB4LGHBJ25RQZKXAM2DE2" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CBLFJZNSQK5UKGAZQEA6VDLORNQKDGGRCOUTB4LGHBJ25RQZKXAM2DE2" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CBLR2XUGJCYW6G2CKWMH764GFLF2MPARBGCSLPZXPMFLL2M35OVS6EWH" --fn-name supply --args '[{"i128":"300000000"}]'

Verify NAV and share price:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CBLFJZNSQK5UKGAZQEA6VDLORNQKDGGRCOUTB4LGHBJ25RQZKXAM2DE2" -- get_nav
stellar contract invoke --network testnet --source-account "deployer" --id "CBLFJZNSQK5UKGAZQEA6VDLORNQKDGGRCOUTB4LGHBJ25RQZKXAM2DE2" -- get_share_price
