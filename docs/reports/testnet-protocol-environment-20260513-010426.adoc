== Testing Instructions

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260513-010426.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CAMOLLWUVKEGGN24M7KXLS7L4GSJGKXJQHWXE7KSR462B25QTROKG2JS" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CBZW4M7FI2P3ITOR7Q2JGXFNKMQYP6TVPLUMK724MX3BPY2HUZHXLJOT" -- deposit --amount 1000000000 --from <G...USER> --asset "CAMOLLWUVKEGGN24M7KXLS7L4GSJGKXJQHWXE7KSR462B25QTROKG2JS" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CBZW4M7FI2P3ITOR7Q2JGXFNKMQYP6TVPLUMK724MX3BPY2HUZHXLJOT" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CBZW4M7FI2P3ITOR7Q2JGXFNKMQYP6TVPLUMK724MX3BPY2HUZHXLJOT" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CCIHHF6DFHCHBU4BEARXBECIDEI6WND4GIJAKU27MH6XEC5TO3IZMYZD" --fn-name supply --args '[{"i128":"300000000"}]'
