== Testing Instructions

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260512-174827.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CAVJMTJM2OWFFT7TOUXSFZLJUO2F2LOFIUK4Q67GLSJBHAZOXI4AMOT6" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CA3NT4HX65OKWX66AJQJIQSQAUZBXWLQ262AOMCM6GM44LWTH7QDYWNX" -- deposit --amount 1000000000 --from <G...USER> --asset "CAVJMTJM2OWFFT7TOUXSFZLJUO2F2LOFIUK4Q67GLSJBHAZOXI4AMOT6" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CA3NT4HX65OKWX66AJQJIQSQAUZBXWLQ262AOMCM6GM44LWTH7QDYWNX" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CA3NT4HX65OKWX66AJQJIQSQAUZBXWLQ262AOMCM6GM44LWTH7QDYWNX" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CAYNLY5DJE5R7HIH3PFPLOBUIO7KYN5PLDYMXV3V55PFSI4NTP3QVW45" --fn-name supply --args '[{"i128":"300000000"}]'
