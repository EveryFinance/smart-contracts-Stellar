== Testing Instructions

----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260513-014257.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CBM5WAL3LHIHLSBGIXW5O64Q47NNEORWYGCO37DDQXPQAZLIAH42NS5K" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CCXGOBKQWH2P7FEQW54TQRZOP2ZSLYZFW5FY6JD2HDMTPL65ZSPN2SOY" -- deposit --amount 1000000000 --from <G...USER> --asset "CBM5WAL3LHIHLSBGIXW5O64Q47NNEORWYGCO37DDQXPQAZLIAH42NS5K" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CCXGOBKQWH2P7FEQW54TQRZOP2ZSLYZFW5FY6JD2HDMTPL65ZSPN2SOY" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CCXGOBKQWH2P7FEQW54TQRZOP2ZSLYZFW5FY6JD2HDMTPL65ZSPN2SOY" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CCLAADS3IAOQJ4QCEN4WJVIPKSMZULAXQAECYZPZIQOLGN76PJNL3E4Y" --fn-name supply --args '[{"i128":"300000000"}]'
