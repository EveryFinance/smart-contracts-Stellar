== Constructor Fix Recorded

The vault constructor no longer requires manager/trader account auth during
contract creation. Soroban rejects that constructor-time account authorization
path on testnet deployment. Post-deployment role-protected operations still
require the configured role signatures.

The share token admin is now assigned to the deterministic future vault address
before vault deployment. The vault constructor verifies that the share token
admin is already the current vault address and does not perform nested
`share_token.set_admin(...)` during construction.

== Testnet Run Notes

The deployment completed and produced the environment files above. The raw
transaction report records the original failures observed during the first
full-environment run: full-NAV snapshot calls and manager `execute_op` demo
actions exceeded Stellar testnet budget when the demo vaults had several active
guards and, for Beta, a broad portfolio asset list.

The contract fix replaces hot-path full scans with bounded accounting indexes:
`TrackedAssets` for non-zero idle asset balances and `PositionGuards` for
non-zero strategy positions. Deposits, withdrawals, seed deposits, and manager
operations update touched indexes automatically. Keepers can also call
`sync_asset_balance(asset)` and `sync_guard_position(guard)` after external
balance/yield changes. `execute_op` now checks the NAV-loss guard against the
local value surface touched by the operation instead of scanning the entire
vault.

The historical raw report is kept as evidence of the failure mode that drove
the fix. A fresh deployment run should be generated after redeploying the
updated vault WASM.

== Testing Commands

Source the deployment:

[source,bash]
----
source deployments/testnet-protocol-environment-20260512-065554.env
----

Mint test USDC:

[source,bash]
----
stellar contract invoke --network testnet --source-account "$SOURCE_ACCOUNT" \
  --id "$USDC_ID" -- mint --to "$USER1_ADDR" --amount 1000000000
----

Deposit USDC:

[source,bash]
----
stellar contract invoke --network testnet --source-account "$USER1_KEY" \
  --id "$ALPHA_VAULT_ID" -- deposit \
  --amount 1000000000 --from "$USER1_ADDR" --asset "$USDC_ID" --min-shares-out 0
----

Withdraw after cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account "$USER1_KEY" \
  --id "$ALPHA_VAULT_ID" -- withdraw \
  --share_amount 100000000 --from "$USER1_ADDR" --to "$USER1_ADDR" --min-base-out 0
----

Verify NAV and share price:

[source,bash]
----
stellar contract invoke --network testnet --source-account "$SOURCE_ACCOUNT" --id "$ALPHA_VAULT_ID" -- get_nav
stellar contract invoke --network testnet --source-account "$SOURCE_ACCOUNT" --id "$ALPHA_VAULT_ID" -- get_share_price
----
