----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CD5NOTLTH4YWQZFOBJMYUY2BGLJYGW57LVYCDDIHHO522T6RLHO3RU3Q" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CCIXHCKUZX6ZIZMWJGVPV6IAKJIKMCYEE6CUMODZTBW7MNJCS3NXNLGC" -- deposit --amount 1000000000 --from <G...USER> --asset "CD5NOTLTH4YWQZFOBJMYUY2BGLJYGW57LVYCDDIHHO522T6RLHO3RU3Q" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CCIXHCKUZX6ZIZMWJGVPV6IAKJIKMCYEE6CUMODZTBW7MNJCS3NXNLGC" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CCIXHCKUZX6ZIZMWJGVPV6IAKJIKMCYEE6CUMODZTBW7MNJCS3NXNLGC" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CC5UQ5ADSIDMU4RDNBJEZ33FSAPZBHEOEDOAN2L43AXWCRHYRFBLKPGO" --fn-name supply --args '[{"i128":"300000000"}]'
