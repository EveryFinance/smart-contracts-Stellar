== Testing Instructions

Source deployment variables:

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260512-165947.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CDPZ5L2QWLOVVACUNAWCMXE34MIQBTY2AVCTJM36NYPZBNORV3DICZEJ" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CBXBBEUJYZKPOUEPDMPLJSHHPGRYYAWRVSQFYO4VHOSD2L4IU3INICOS" -- deposit --amount 1000000000 --from <G...USER> --asset "CDPZ5L2QWLOVVACUNAWCMXE34MIQBTY2AVCTJM36NYPZBNORV3DICZEJ" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CBXBBEUJYZKPOUEPDMPLJSHHPGRYYAWRVSQFYO4VHOSD2L4IU3INICOS" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CBXBBEUJYZKPOUEPDMPLJSHHPGRYYAWRVSQFYO4VHOSD2L4IU3INICOS" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CBJZ7K7ULZWSR26EKUNFGZF3UT466DDT2XOKIUPCK76L5K236Q4SJKAM" --fn-name supply --args '[{"i128":"300000000"}]'
----

Verify NAV and share price:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CBXBBEUJYZKPOUEPDMPLJSHHPGRYYAWRVSQFYO4VHOSD2L4IU3INICOS" -- get_nav
stellar contract invoke --network testnet --source-account "deployer" --id "CBXBBEUJYZKPOUEPDMPLJSHHPGRYYAWRVSQFYO4VHOSD2L4IU3INICOS" -- get_share_price
