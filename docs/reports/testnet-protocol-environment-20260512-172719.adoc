== Testing Instructions

Source deployment variables:

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260512-172719.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CB4M553EUFAO5KHSM4EA6ILB5LCL3LM6RFRFO2CKGIVQMYNCTZNATXVX" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CAON76FT5SATTXAZLWF7JJKFXPGZWHYKAA32PC7VHKZO27ZT5XOJRLEF" -- deposit --amount 1000000000 --from <G...USER> --asset "CB4M553EUFAO5KHSM4EA6ILB5LCL3LM6RFRFO2CKGIVQMYNCTZNATXVX" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CAON76FT5SATTXAZLWF7JJKFXPGZWHYKAA32PC7VHKZO27ZT5XOJRLEF" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CAON76FT5SATTXAZLWF7JJKFXPGZWHYKAA32PC7VHKZO27ZT5XOJRLEF" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CACRWOSDUJD5Q6NZYTXK32JLDGLDV57AKRAJKKSMEC3G5NZFC25EWMB3" --fn-name supply --args '[{"i128":"300000000"}]'
----

Verify NAV and share price:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CAON76FT5SATTXAZLWF7JJKFXPGZWHYKAA32PC7VHKZO27ZT5XOJRLEF" -- get_nav
stellar contract invoke --network testnet --source-account "deployer" --id "CAON76FT5SATTXAZLWF7JJKFXPGZWHYKAA32PC7VHKZO27ZT5XOJRLEF" -- get_share_price
