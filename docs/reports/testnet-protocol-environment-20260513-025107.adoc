== Testing Instructions

Source deployment variables:

[source,bash]
----
source /home/mohamed/smart-contracts-Stellar/deployments/testnet-protocol-environment-20260513-025107.env
----

Mint test USDC freely for any user:

[source,bash]
----
stellar contract invoke --network testnet --source-account <payer> --id "CAXSSYBR5NB5GKA62PMNGAOUCBQ5TM2N6O5E4SBYJCCIXHMILQPAFKUG" -- mint --to <G...USER> --amount 1000000000
----

Deposit USDC into a vault:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CDDPOJ7TSLHN3D6Z3T5ZUFVV5UIHL6WFNHBA24VOVP6R47T374YVZXKT" -- deposit --amount 1000000000 --from <G...USER> --asset "CAXSSYBR5NB5GKA62PMNGAOUCBQ5TM2N6O5E4SBYJCCIXHMILQPAFKUG" --min-shares-out 0
----

Withdraw shares after the 1 minute cooldown:

[source,bash]
----
stellar contract invoke --network testnet --source-account <user-key> --id "CDDPOJ7TSLHN3D6Z3T5ZUFVV5UIHL6WFNHBA24VOVP6R47T374YVZXKT" -- withdraw --share_amount <shares> --from <G...USER> --to <G...USER> --min-base-out 0
----

Manager lending supply example:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CDDPOJ7TSLHN3D6Z3T5ZUFVV5UIHL6WFNHBA24VOVP6R47T374YVZXKT" -- execute_op --caller "GB2HC2NLXR7LHKXGS2IZL4F5LZVQVKRBKCWONQQW4WIYUXDILHORWQPZ" --guard "CDJXM4NGQODYNDMJOO3ZC6T64UQFCJEBLN3VABFZ5MUHGEV5QXQBI7AZ" --fn-name supply --args '[{"i128":"300000000"}]'
----

Verify NAV and share price:

[source,bash]
----
stellar contract invoke --network testnet --source-account "deployer" --id "CDDPOJ7TSLHN3D6Z3T5ZUFVV5UIHL6WFNHBA24VOVP6R47T374YVZXKT" -- get_nav
stellar contract invoke --network testnet --source-account "deployer" --id "CDDPOJ7TSLHN3D6Z3T5ZUFVV5UIHL6WFNHBA24VOVP6R47T374YVZXKT" -- get_share_price
